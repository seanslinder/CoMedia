# План будущих итераций проекта CoMedia

После успешной реализации базового прототипа (MVP) в рамках текущего семестра, развитие системы предполагается вести итеративным методом. Ниже представлен план последующих этапов разработки для доведения проекта до уровня полноценного коммерческого или open-source продукта к моменту защиты дипломной работы.

## Итерация 1: Текущий статус (MVP)
* Реализована базовая архитектура (Клиент-Сервер-БД).
* Настроена авторизация по JWT.
* Работают WebSocket-комнаты для текстового чата.
* Добавлена базовая синхронизация видеоплеера (Play/Pause/Seek).
* Поддерживается загрузка локальных MP4 файлов на сервер.

---

## Итерация 2: Стабилизация синхронизации и улучшение UX (Пользовательский опыт)
**Цель:** Сделать основной функционал просмотра максимально комфортным и отказоустойчивым.

* **Улучшение алгоритма синхронизации:**
  * Учет сетевой задержки (ping/latency) между клиентом и сервером при расчете позиции видео.
  * Обработка событий буферизации (если у одного пользователя «зависло» видео, пауза ставится у всех, пока видео не догрузится).
* **Модернизация интерфейса:**
  * Переход с базового HTML/CSS на компонентный подход (по желанию — миграция на легковесный фреймворк или использование веб-компонентов).
  * Добавление аватарок пользователей и детального списка активных зрителей.
  * Создание панели администратора комнаты для управления ролями (назначение модераторов, удаление пользователей).
* **Управление очередью (Playlist):**
  * Полноценный UI для drag-and-drop сортировки очереди видео.
  * Плавный автопереход к следующему видео по окончании текущего.

## Итерация 3: Расширение функционала (Интеграции и Communication)
**Цель:** Внедрить продвинутые фичи, востребованные в современных сервисах совместного просмотра.

* **Голосовой и видео чат (WebRTC):**
  * Добавление возможности зрителям общаться голосом параллельно с просмотром видео, используя технологию WebRTC (Peer-to-Peer соединение).
* **Интеграция сторонних сервисов:**
  * Поддержка воспроизведения видео по ссылке из YouTube, Vimeo или Twitch, без необходимости физической загрузки файла на сервер (использование их iframe API с сохранением синхронизации).
* **Продвинутая система профилей:**
  * Регистрация с паролем (хеширование bcrypt), история просмотренных видео, список друзей.

## Итерация 4: Инфраструктура, безопасность и масштабирование (DevOps этап)
**Цель:** Подготовить проект к развертыванию (Production) и высоким нагрузкам.

* **Масштабирование WebSocket-сервера:**
  * Полноценное использование Redis Pub/Sub для возможности запуска приложения в кластерном режиме (несколько экземпляров Node.js сервера за балансировщиком нагрузки).
* **Развертывание (Deployment) и CI/CD:**
  * Настройка непрерывной интеграции (GitHub Actions / GitLab CI) для автоматического запуска тестов и деплоя.
  * Перенос решения на облачный хостинг (например, AWS, Яндекс.Облако или DigitalOcean) с использованием Kubernetes или Docker Swarm.
* **Безопасность и хранение данных:**
  * Перенос хранения загружаемых медиафайлов из локальной папки в облачное объектное хранилище (S3-совместимое).
  * Внедрение Rate Limiting для защиты API от DDoS и брутфорс-атак на ендпоинты авторизации.

---
**Итог:** Выполнение данных итераций позволит продемонстрировать на защите дипломной работы не только навыки прикладного программирования, но и глубокое понимание процессов проектирования систем, работы с сетями, распределенными базами данных и современными DevOps-практиками.
